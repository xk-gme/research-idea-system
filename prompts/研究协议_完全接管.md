# 研究协议：agent 完全接管（形态三）

适用对象：任何被授权独立完成"研究想法生成"的 agent 会话。本路径把 research 阶段完全交给 agent 自由执行（检索自由度最高、协议约束最少），代价是**证据等级最低**：没有有界调用日志，来源由 agent 自行声明。产物必须通过 `takeover` 命令的校验才能进入后续流程，manifest 会明确标注 `provenance_tier: agent_takeover`。**不得作为正式论文复现路径引用**（正式路径为 research/coscientist 管线）。

## 你的任务

1. **读取任务背景**：`prompts/任务背景/<任务名>.md` 全文是你的研究纲要。
2. **自由研究**：用你拥有的任何工具（搜索、浏览、已有知识）围绕任务收集方法思路。建议先按 S15 的原则清单（任务背景里已含）逐条寻找候选方法族。
3. **产出想法**：10 个高度新颖、彼此机制不同的想法，每个想法必须：
   - `title`：简短方法名；
   - `idea`：方法机制描述（150–400 字，说明为什么可能优于常规做法）；
   - `implementation_notes`：落地要点（数据接口、关键算法步骤、主要风险）；
   - `sources`：**非空**的 http(s) URL 列表，是你真实参考过的来源（论文页、文档、代码仓库均可）。禁止编造 URL。

## 输出格式（ideas.json）

```json
{
  "ideas": [
    {
      "title": "Growth-rate anchored quantile ensemble",
      "idea": "...",
      "implementation_notes": "...",
      "sources": ["https://arxiv.org/abs/...", "https://..."]
    }
  ]
}
```

## 硬性规则（takeover 校验项）

1. 顶层必须是含非空 `ideas` 数组的 JSON 对象；
2. 每条必须有非空 `title` 与 `idea`（或 `hypothesis`）文本；
3. 每条必须有非空 `sources`，元素全为 http(s) URL；
4. 标题不得重复；
5. 自我声明边界：你是模型替代路径上的自由研究，不是论文协议的复现——在给你的用户报告里如实说明这一点。

## 登记

```bash
python -m idea_system.pipeline takeover --task <任务名> --file <你的ideas.json路径>
```

校验通过后想法登记为 R1…（origin=agent_takeover），来源收敛为 S 编号记录（source=agent_claimed，代表"由 agent 声明、未独立核验"）。之后照常 `filter` → `format` 进入 S16 方法卡。
