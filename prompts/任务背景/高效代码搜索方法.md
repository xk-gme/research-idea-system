# 任务背景：降低 LLM 驱动的代码搜索/优化成本

供研究想法系统 S15 使用。接口与原论文协议一致：S15 生成想法→锦标赛评审→人工筛选→S16 格式化。
以下英文正文为给模型的任务背景。

---

I am developing methods to make LLM-driven program search and code optimization more compute-efficient. The current state of the art uses tree search algorithms (e.g., Flat-UCB/PUCT tree search) where a large language model generates candidate programs, each candidate is evaluated in a sandbox, and the search tree explores promising branches. However, this approach is extremely token-expensive: each node consumes approximately 29,000 tokens (including the prompt with parent code and the model's response with thinking), and a single search run may need thousands of nodes.

The key problem is to develop methods that achieve comparable or better code quality while consuming significantly fewer LLM tokens. Specifically, the method should define a clear strategy for how to generate, evaluate, and select candidate programs (or program descriptions) that reduces the total token budget by at least 5x compared to naive tree search.

The following principles should be obeyed when choosing methods:

* **Token Efficiency**: The total token consumption (prompt + completion) should be explicitly minimized. Methods that reuse information across iterations (e.g., caching, summarization, compression) are preferred over methods that resend full context.
* **Quality Preservation**: The method should maintain or improve the quality of the final program compared to tree search baselines. Quality is measured by the task-specific metric (e.g., WIS for forecasting, accuracy for classification).
* **Practical Feasibility**: The method should be implementable with current LLM APIs (OpenAI-compatible, DeepSeek). No access to model weights or gradients is assumed.
* **Search Space Awareness**: The method should leverage the structure of the program search space (e.g., incremental modifications are often small, programs share common patterns, evaluation feedback is informative).
* **Convergence Guarantees**: Prefer methods with theoretical or empirical evidence of convergence (e.g., Bayesian optimization with regret bounds, evolutionary strategies with convergence analysis).

This task aims to develop a SUPERHUMAN METHOD for solving this problem.

Please give me 10 highly novel and creative ideas with detailed implementation notes for the set of methods I should explore for solving this task. I aim to create the best method for solving this problem, preferably creating the best ever method.
